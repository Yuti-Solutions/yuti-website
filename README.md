# Yuti Solutions — Official Website

Official static website for **Yuti Solutions** (*Uniting Systems & Wisdom*).

## Overview
Yuti Solutions is a technology and software consulting firm delivering custom website development, scalable web applications, IT consultation, and ongoing system maintenance.

## Tech Stack
- **HTML5** & semantic markup
- **CSS3** with custom design system, glassmorphism, and responsive CSS Grid/Flexbox
- **Vanilla JavaScript** (lightweight navigation, scroll observers, dynamic interactions)
- Zero external build dependencies

## Project Structure
```text
├── index.html              # Main website landing page
├── styles.css              # Custom styling & responsive layouts
├── script.js               # Client-side interactivity & animations
├── Logo.png                # Primary brand logo
├── Banner.png              # Hero & promotional banner
├── favicon.ico             # Browser favicon
├── android-chrome-*.png    # PWA / mobile app icons
├── apple-touch-icon.png    # iOS touch icon
├── assets/                 # Brand visual assets
└── .gitignore              # Git ignore rules
```

## Local Development
Open `index.html` directly in any modern browser, or run a local HTTP server:
```bash
python3 -m http.server 8000
```
Then navigate to `http://localhost:8000`.
